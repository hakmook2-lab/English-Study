# Let's Talk! 영어 공부

가족 영어 공부 웹앱 (단어 카드 · 문장 말하기 · 역할극 · 자동재생 · 퀴즈 · 철자 쓰기)

## 처음 올리기
1. github.com → 오른쪽 위 **+** → **New repository**
2. Repository name: `Lets-Talk` / **Public** 선택 / Create repository
   - "Start free for 30 days"(Enterprise 체험)는 누르지 않기
3. 저장소 화면 → **Add file → Upload files** → 파일 7개를 전부 선택해 끌어다 놓기 → **Commit changes**
   - 폴더 없이 파일만 올리면 됩니다 (하위 폴더 없음)
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main / (root)** → **Save**
5. 1~2분 뒤 주소: `https://hakmook2-lab.github.io/Lets-Talk/`
   - 주소는 한 번 정한 뒤 바꾸지 않기 (주소가 바뀌면 폰에 저장된 진도가 안 보임)

## 업데이트할 때
1. 새 파일을 받으면 **Add file → Upload files** → 같은 이름 파일을 다시 끌어다 놓기 (자동으로 덮어씀) → **Commit changes**
2. 1~2분 뒤 **Actions** 탭에 초록 체크가 뜨면 완료
3. 폰에서 앱을 새로고침 (안 바뀌면 앱을 완전히 닫았다 다시 열기)
- sw.js 맨 위 VERSION이 올라가 있어야 폰의 오프라인 저장본이 새 버전으로 바뀝니다

## 진도 옮기기 (미리보기 링크 → GitHub 주소)
- 이전 주소에서: 설정 → 진도 백업·복원 → 백업 코드 만들기 → 복사
- 새 주소에서: 설정 → 같은 칸에 붙여넣기 → 복원
